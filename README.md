# 🔧 Hardware, Embedded & VLSI Projects

## 6. 5-Stage Pipelined RISC-V Processor

**Repository:**  
https://github.com/mlr-pravallika/5-Stage-Pipelined-RISC-V-Processor-with-Hazard-Detection-and-Forwarding

A Verilog-based implementation of a **5-stage pipelined RISC-V processor** with hazard detection and forwarding mechanisms.

### Pipeline Architecture

```text
Instruction Fetch
       ↓
Instruction Decode
       ↓
Execute
       ↓
Memory Access
       ↓
Write Back
```

### Implemented Components

- Program Counter
- Instruction Fetch
- IF/ID Pipeline Register
- Register File
- Control Unit
- ID/EX Pipeline Register
- ALU
- EX/MEM Pipeline Register
- MEM/WB Pipeline Register
- Hazard Detection Unit
- Forwarding Unit

### Technologies

`Verilog` `RISC-V` `RTL Design` `EDA Playground` `Icarus Verilog` `EPWave`

# 💻 Running the Project Locally

### Clone the repository

```bash
git clone https://github.com/mlr-pravallika/pravallika-portfolio.git
```

### Navigate into the project

```bash
cd pravallika-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available through the local development URL shown in your terminal.
